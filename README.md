# Argo Ocean Monitoring
## Система мониторинга океанологических условий и выявления потенциальных аномалий Мирового океана

### 1. О проекте

**Argo Ocean Monitoring** — учебный исследовательский проект, посвящённый обработке и анализу данных автономных океанографических буёв международной программы Argo.

Цель проекта — разработать прототип аналитической системы, которая объединяет данные из нескольких источников, проверяет качество измерений, анализирует вертикальную структуру океана и выявляет потенциальные статистические отклонения температуры и солёности.

Результаты могут использоваться как дополнительная информационная основа для океанологических и климатических исследований.

Важно: система не является самостоятельным прогнозом штормов, ураганов или иных атмосферных явлений. Для такого прогнозирования необходимы дополнительные метеорологические и гидродинамические данные.

### 2. Используемые источники данных

В проекте используются два источника.

**Статический датасет**
- Название: [Otter21/ARGO_Profiles](https://huggingface.co/datasets/Otter21/ARGO_Profiles)
- Платформа: Hugging Face.
- Использованная выборка: 100 профилей Argo.
- Содержит измерения температуры, солёности, давления и дополнительные биогеохимические параметры.

**Оперативный источник**
- Название: [Argovis API](https://argovis-api.colorado.edu)
- Документация: https://argovis-api.colorado.edu/docs/
- Получены метаданные за период 25 октября — 24 ноября 2026 года.
- Для детальной обработки загружены 20 профилей Argo.

Таким образом, объединённая выборка содержит 120 профилей из двух источников.

### 5. Этапы обработки данных

1. Загрузка статического набора профилей Argo.
2. Получение оперативных профилей через Argovis API.
3. Преобразование вложенных структур JSON в табличный формат.
4. Нормализация измерений по вертикальным уровням.
5. Объединение данных двух источников.
6. Контроль качества измерений температуры, солёности и давления.
7. Исключение некорректных измерений из основной аналитической выборки с сохранением отклонённых записей.
8. Формирование аналитической витрины по бассейнам, месяцам и глубинным слоям.
9. Расчёт статистических характеристик профилей.
10. Выявление потенциальных статистических аномалий.
11. Классификация профилей по уровням мониторинга.
12. Построение графиков и сохранение результатов.

### 6. Контроль качества

В основной аналитической выборке применены следующие технические ограничения:

- давление: от 0 до 12 000 dbar;
- температура: от −2,5 до 40 °C;
- солёность: от 20 до 42;
- для QC-показателей допускаются значения 1, 2 и отсутствие значения QC.

Значения солёности ниже 20 исключались из основной аналитической выборки как подозрительные для выбранного набора данных. Это технический фильтр данного исследования, а не универсальная граница допустимой океанической солёности.

Исходные данные не удалялись: исключённые измерения сохранялись отдельно для последующей проверки.

### 8. Система уровней мониторинга

Для предварительной оценки профилей используется доля потенциально аномальных измерений в каждом профиле.

Применяются следующие экспериментальные пороги:

| Уровень | Условие |
|---|---|
| Отклонения не обнаружены | 0% |
| Низкий | Более 0% и не более 1% |
| Умеренный | Более 1% и не более 5% |
| Высокий | Более 5% |

Результаты классификации:

| Уровень | Количество профилей |
|---|---:|
| Высокий | 26 |
| Низкий | 12 |
| Отклонения не обнаружены | 55 |
| Умеренный | 17 |
| **Всего** | **110** |

Указанные пороги являются предварительными аналитическими критериями проекта. Они не представляют собой официальные уровни погодной или океанологической опасности.

### 9. Визуализация

- вертикального распределения солёности по бассейнам;
- распределения средней температуры по бассейнам и глубинным слоям;
- количества измерений по глубинным слоям;
- распределения профилей по уровням мониторинга;
- средней доли потенциальных аномалий по бассейнам;
- десяти профилей с наибольшей долей потенциальных аномалий.

Графические результаты сохраняются в `data/mart/figures/`.

### 10. Ограничения исследования

- Выборка ограничена 120 профилями, поэтому результаты не описывают весь Мировой океан.
- Данные двух источников относятся к разным периодам: статическая выборка — ноябрь 2024 года, оперативная — ноябрь 2026 года.
- Сравнение этих периодов не позволяет самостоятельно делать выводы о долгосрочных временных трендах.
- Количество профилей по бассейнам неодинаково.
- Статистическое отклонение не обязательно означает ошибку измерения или реальную физическую опасность.
- Соседние измерения одного профиля могут быть зависимыми друг от друга.
- Для полноценного прогноза погодных опасностей необходимы дополнительные данные об атмосфере, ветре, волнении и океанической циркуляции.

### 11. Перспективы развития

В дальнейшем проект можно расширить за счёт:

- увеличения количества загружаемых профилей Argo;

- улучшения статистических критериев выявления отклонений;

- применения методов машинного обучения;

- разработки интерактивной карты мониторинга;

- формирования автоматических уведомлений при обнаружении значимых отклонений.

12. Назначение проекта
